# 网易云音乐歌单导出工具 (CloudMusic Exporter)

一个精美、现代且安全的 Edge / Chrome 浏览器扩展插件，支持一键解析并导出网易云音乐歌单、排行榜及专辑中的歌曲名、歌手和专辑信息。

## 🌟 功能特色

*   **穿透式 iframe DOM 爬取**：智能穿透网易云网页版中嵌套的 `g_iframe` DOM 容器，无论在主页面还是独立页面都能精准提取。
*   **部分歌曲勾选导出**：支持在插件中直观浏览解析出的歌曲列表，提供一键全选、反选及手动勾选，只导出您需要的歌曲。
*   **多格式高保真支持**：
    *   **CSV 格式**：带 UTF-8 BOM 前缀（Excel 打开中文不乱码），且对双引号进行规范转义。
    *   **JSON 格式**：标准的结构化数据，提供优雅的排版缩进。
    *   **TXT 格式**：生成排版精美的纯文本歌曲编号列表，附加歌单名称及导出时间元信息。
*   **零敏感权限申请**：完全在本地沙箱运行，采用 Blob 触发浏览器本地下载，**不需要获取浏览器的 `downloads` 敏感控制权限**，保护您的隐私。
*   **高颜值科技感 UI**：采用网易云火焰红渐变、半透明毛玻璃卡片（Glassmorphism）和流畅的加载与成功提示微动画，带来极致的使用体验。

## 🛠️ 安装方法

1.  下载本项目的所有代码到本地文件夹。
2.  打开 Microsoft Edge (或 Google Chrome) 浏览器，在地址栏中输入 `edge://extensions/` (Chrome 中输入 `chrome://extensions/`) 并回车。
3.  在扩展管理页面中，开启 **“开发人员模式”** (Developer mode) 开关。
4.  点击左上角出现的 **“加载解压的扩展”** (Load unpacked) 按钮。
5.  在弹出的文件夹选择器中，选中包含本项目代码的根目录（即包含 `manifest.json` 的目录）。
6.  点击“选择文件夹”即可加载成功！插件图标将出现在您的浏览器插件栏中。

## 📖 使用指南

1.  打开网易云音乐网页版：例如 [网易云热歌榜](https://music.163.com/#/discover/toplist?id=3778678) 或者是您自己收藏的歌单详情页。
2.  **确保歌单歌曲列表已经在页面上完全加载显示出来**。
3.  点击右上角插件栏的 **网易云音乐歌单导出** 图标，打开插件弹窗。
4.  插件会自动连接当前标签页，状态灯变为绿色，提示“已连接网易云音乐页面”。
5.  点击 **“一键解析当前页面”** 按钮。
6.  解析成功后：
    *   上方会显示当前已勾选的歌曲总数；
    *   中间会展开歌曲多选列表，您可以手动取消勾选某些歌曲，或者使用“全选/反选”快速操作；
    *   您可以自定义导出的文件名，并选择导出的格式（CSV、JSON、TXT）。
7.  点击 **“确认导出并下载”**，文件即会成功保存到您的本地下载文件夹中。

本插件为开源的纯静态客户端插件，不含任何统计代码或第三方 SDK。所有抓取与文件生成流程均在您的本地浏览器中完成，绝不会收集您的账号信息、Cookie 或向任何外部服务器上传数据。
